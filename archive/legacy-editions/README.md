# Legacy Editions Archive

本目录收档了 CMath 数学地图（Math Map）的历史演进版本快照。

## 包含文件

- `index-v2.html` / `app-v2.js` / `app-v2.css`: V2 历史版本工作台与交互脚本。
- `index-v4.html` / `app-v4.css`: V4 历史版本（Proof Edition）。

## 归档说明与使用限制

1. **历史快照，非当前生产入口**：
   当前仓库的生产入口为根目录下的 `index.html`（与 `index-v5.html`），配合 `app-v5.js` / `app-v5.css` 提供最新的工作台、论文解析流以及数学地图交互能力。本目录下的文件仅作为历史参考快照保留。

2. **相对路径依赖与非独立运行声明**：
   这些历史页面在设计时均假定部署在仓库根目录，其内部引用的样式、图标、渲染依赖和通用模块（如 `styles.css`、`vendor/`、`math-map-lab.css` 等）均为基于根目录的相对路径。因此，**在归档到子目录后，这些文件并不能直接独立运行**。若需复现或测试历史版本，必须将其置于原先预期的根目录相对路径层级中进行服务。
