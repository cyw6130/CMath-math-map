# Sol-only Workflow Optimization Process Acceptance

Date: 2026-08-29

Issue: #49

## Accepted boundary

- The regression suite remains the five active records in `source-manifest.json`.
- Generalization suite `v1` is released and immutable with one frozen MinerU source in algebra, analysis, number theory, and combinatorics.
- Quick uses regression only. Candidate and Final use both suites. Only Final has promotion authority.
- Entry, W7.1, W8, Inference, source scoring, and evaluation scoring are all bound to `luna-gateway / gpt-5.6-sol / medium`.
- Every experiment has one changed semantic stage, a baseline workflow identity, a candidate module identity, suite identities, per-case source identities, and exact case membership.
- Completion fails if a case is missing, duplicated, source-rebound, generated by a non-Sol model, evaluated by a non-Sol model, or lacks content-addressed artifact/evaluation identities.
