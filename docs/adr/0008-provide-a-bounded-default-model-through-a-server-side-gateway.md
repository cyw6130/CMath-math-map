# 通过服务端网关提供受限的默认模型

日期：2026-08-30 · 状态：Accepted

## 背景

公开网站当前要求访问者先配置自己的模型供应商、端点、模型与 API Key，才能执行 Paper Import。这个前置配置提高了首次使用门槛。OpenCode Go 提供低成本的 Muse Spark 1.2 Contributor，因而可以让访问者在不配置模型凭证的情况下先体验论文转地图。

静态前端无法保守共享 API Key：任何能够从浏览器直接调用上游模型的凭证，无论经过压缩、混淆或拆分，都能从运行代码或网络请求中恢复。Muse Spark 1.2 Contributor 还使用 Responses API，而现有生产客户端只实现 Chat Completions API；同时，该 Contributor 模型允许使用输入与输出训练未来模型，并有地区限制。

## 决定

1. CMath 增加“CMath 提供的模型服务”，首个候选模型为 OpenCode Go 的 Muse Spark 1.2 Contributor，准确模型 ID 为 `muse-spark-1.2-contributor`。
2. OpenCode Go API Key 只保存在独立服务端模型网关的 Secret 中。静态前端、构建产物、浏览器存储、日志、错误信息和生成地图都不得包含或取得该 Key。
3. 模型网关只接受固定来源、固定模型和受限合同的请求，并限制请求大小、并发与异常高频访问；必须具备全局费用熔断、拒绝滥用和紧急停用能力，不能成为通用模型代理。第一版不设置用户可见的每日次数，也不限制正常频率下的连续使用。
4. 该服务先以受保护试用发布。正式向匿名公众开放前，必须确认上游服务条款允许此种第三方转发使用。
5. Muse Spark 路径使用上游规定的 Responses API，不把它伪装成现有 Chat Completions 模型。生产客户端增加显式传输适配，并接受独立测试。
6. Muse Spark Contributor 可能使用论文输入与模型输出训练未来模型。用户首次通过该路径提交论文前，界面必须以简明文字披露并取得主动同意；不同意的用户可以改用 User-provided Model Access。
7. User-provided Model Access 继续保留，与默认模型服务形成两条明确路径。共享服务的凭证、额度和状态不得进入用户自带配置。
8. 设置首页先选择“CMath 提供”或“使用自己的 API”。前者默认选中，只展示 Muse Spark、服务状态与隐私说明；后者才展开供应商、端点、API Key、模型、连接测试与保存配置表单。
9. 训练用途授权不在设置阶段索取，而是在用户点击“生成数学地图”后、论文内容首次提交给模型前索取。授权按披露版本保存在本地；披露内容变化后必须重新取得同意。
10. 默认服务额度耗尽、地区不可用或网关故障时，保留用户已选 PDF 与安全进度，提供“稍后重试”和“使用自己的 API”；不得静默切换模型、凭证或数据政策。
11. CMath-provided Model Access 只提供 Muse Spark，不把共享凭证扩展为 OpenCode Go 模型选择器；其他模型仅能通过 User-provided Model Access 使用。
12. 首次访问默认选择 CMath-provided Model Access。用户保存过自己的模型配置后，记住其最后使用的访问模式；再次进入设置时不得擅自切回共享服务。

## 取舍

- 不在前端隐藏或混淆共享 Key，因为这只能增加提取步骤，不能形成安全边界。
- 不把现有 MinerU Credential Gateway 扩展成任意上游代理；模型网关拥有独立凭证、请求合同、额度和停用边界。
- 不以零配置为由省略训练用途告知。降低首次使用门槛不能覆盖论文数据的知情选择。
- 不承诺无限免费使用；可用性服从试用额度、上游地区限制和服务状态。

## 后果

- 首次用户可以在不进入设置、不提供 API Key 的情况下开始 Paper Import。
- 设置界面需要区分“CMath 提供”与“使用自己的模型 API”，并只在后一条路径展示供应商、端点和 Key 表单。
- 默认服务不可用或额度耗尽时，界面必须显式说明原因，并给出切换到用户自带配置的路径，不能静默换模型或借用其他凭证。
- ADR-0005 中“网站不提供或代理模型服务”被本决定部分取代；User-provided Model Access 与其他生产复现约束继续有效。
