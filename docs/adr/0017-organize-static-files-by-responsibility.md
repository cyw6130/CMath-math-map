# 静态文件按职责归入子目录

日期：2026-09-05 · 状态：Accepted

## 背景与授权

用户明确要求“按文件夹整理一下”，并要求 README 与实际目录一致。此前 README 中要求运行资源平铺根目录的约定由本决定替代；ADR-0010 的单一发布清单与入口镜像规则继续有效。

## 决定

- 根目录保留 `index.html`、`index-v5.html`、`server.js` 及项目配置和说明。
- 自有脚本按工作台、论文导入、地图、存储与兼容用途归入已有 `src/` 子目录；辅助页面归入 `pages/`，CSS 和图片归入 `assets/styles/`、`assets/images/`。
- 同步的浏览器能力移到 `capabilities/browser/`，内容逐字保留。第三方 `vendor/` 一并放在其下，保持能力加载器内部的相对地址，无需修改上游能力实现。
- 同步更新 CMath-capabilities 的 `registry/runtime-consumers.json` 中本项目的目标路径，以及本项目消费清单。其他消费者、能力来源与数学合同不变。
- 辅助页面使用 `<base href="../">`，生产入口仍使用项目根相对路径。本地、桌面和 GitHub Pages 共用同一套目录；不新增构建框架或重复的资源映射层。

## 验收

迁移只改变位置和引用，不改变算法、凭证策略与数学语义。检查生产清单、HTML/CSS 资源、本地服务、地图渲染及模块引用；同步能力移动前后的哈希必须一致。原有未提交改动保留，不纳入本次提交。
